# Contributing

This project is provided as-is.

## Issues

Issues are welcome. Use the bug report or feature request template.

## Pull requests

We do not accept pull requests. To ask for a change, open an issue that describes it.

## Security

To report a vulnerability, read [SECURITY.md](SECURITY.md). Do not open a public issue for a vulnerability.

## Code of Conduct

The [Code of Conduct](CODE_OF_CONDUCT.md) applies to all spaces of this project.
